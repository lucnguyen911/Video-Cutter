# Video Auto Cut by Lực Nguyễn

Tool cắt video tự động theo thời lượng hoặc chuyển cảnh.

## Tính năng

- Chọn video đầu vào
- Chọn thư mục xuất
- Cắt theo thời lượng cố định
- Cắt theo chuyển cảnh
- Làm mượt điểm cắt
- Chia output thành nhiều folder
- Xóa audio tùy chọn
- Hủy tiến trình và tự xóa file tạm
- Mở thư mục kết quả sau khi hoàn thành

## Cách chạy khi còn là code

```cmd
.venv\Scripts\activate.bat
python main.py
